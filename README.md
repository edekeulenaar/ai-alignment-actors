# PoP — Alignment actors site

Static GitHub Pages site visualising the actors involved in AI alignment
across model cards, policies, principles, grants and audits.

## Files

- `index.html` — page structure (Introduction, Method, Findings, Discussion)
- `style.css`  — layout, color tokens, document-type icons
- `app.js`     — renders the grid, filters, hover cards, click highlighting
- `data.json`  — generated by `python3 build_site_data.py` (one folder up)

## Rebuild data

After editing `details_all.csv`, re-run the preprocessor:

```bash
cd "PoP - Alignment actors"
python3 build_site_data.py
```

## Local preview

```bash
cd docs
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy to GitHub Pages

1. Push the repo to GitHub.
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / folder: `/docs`.
3. The site will be live at `https://<user>.github.io/<repo>/` within a minute.

## Tweaks

- **Show more companies:** edit `TOP_N_COMPANIES` in `app.js` (default 10).
- **Actor-type palette:** change CSS variables `--c-internal`, `--c-private`, … in `style.css`.
- **Document-type icons:** edit the `.doc.t-*` rules in `style.css`.
- **Section copy:** edit `<section id="introduction">` etc. in `index.html`.
